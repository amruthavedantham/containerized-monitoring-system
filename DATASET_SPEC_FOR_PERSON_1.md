# Dataset Specification & Metric Handoff for Person 1

## Overview
This specification details the required features and metric schema for generating the synthetic load test dataset using Locust and Prometheus. Person 2 will use this dataset to train the final **Isolation Forest** anomaly detection model.

---

## Required Dataset Schema (CSV Format)

The CSV dataset generated during Locust load testing MUST contain the following 8 columns:

| Column Name | Data Type | Units | PromQL Query / Derivation | Description |
| :--- | :--- | :--- | :--- | :--- |
| `timestamp` | string / int | ISO8601 or Epoch seconds | System timestamp | Time of metric snapshot (sampled every 5 seconds) |
| `request_rate` | float | requests / sec | `rate(http_requests_total[1m])` | Overall HTTP request rate |
| `avg_response_latency` | float | seconds | `rate(http_request_duration_seconds_sum[1m]) / rate(http_request_duration_seconds_count[1m])` | Average request response time |
| `p95_response_latency` | float | seconds | `histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[1m]))` | 95th percentile request latency |
| `error_rate` | float | errors / sec | `rate(http_errors_total[1m])` | Rate of 5xx HTTP errors |
| `active_requests` | float | count | `http_requests_in_progress` | Number of requests currently being processed |
| `cpu_usage_pct` | float | percentage (0-100) | `rate(process_cpu_seconds_total[1m]) * 100` | CPU utilization of application container |
| `memory_usage_mb` | float | MB | `process_resident_memory_bytes / (1024 * 1024)` | Resident set memory usage |

---

## Instructions for Locust Load Generation

To ensure the Isolation Forest model learns both normal baseline patterns and anomalous failure modes, the Locust scenarios generated by Person 1 should include:

1. **Normal Baseline Traffic (~70% of dataset)**:
   - Steady low-to-moderate request rate (5 - 30 req/sec)
   - Low response times (< 0.2s)
   - Zero or near-zero error rate
   - Stable memory and CPU usage

2. **Traffic Spike Anomaly (~10% of dataset)**:
   - Rapid surge in request rate (100+ req/sec)
   - Moderate increase in latency and CPU

3. **High Latency / Slow Service Anomaly (~10% of dataset)**:
   - High volume of calls to `/slow` endpoint
   - Spike in `avg_response_latency` (> 1.5s) and `p95_response_latency` (> 2.0s)
   - Increased `active_requests` gauge due to thread saturation

4. **Server Failure / Error Storm Anomaly (~10% of dataset)**:
   - High volume of calls to `/error` endpoint
   - High `error_rate` (5xx errors) while latency may remain low

## Missing Value & Sampling Rules
- **Sampling Interval**: 5 seconds per row.
- **Null / Missing Values**: Replace missing gauge values with `0.0` or previous value (`ffill`).
- **File Naming**: Export final CSV as `prometheus_locust_dataset.csv`.
